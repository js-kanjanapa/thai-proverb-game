Thai Proverb Game Project

A Python terminal-based game developed using Object-Oriented Programming (OOP) principles.

Core Concepts Applied

Python Fundamentals: String manipulation, control flows, and data structures (lists, tuples, dictionaries).
Object-Oriented Programming (OOP): Modular architecture using class inheritance (`TextProverbQuestion`, `ChoiceProverbQuestion`, and `ProverbGame`).
Error Handling: Input validation using `try...except` blocks to prevent runtime crashes.
Version Control: Project management and deployment via Git and GitHub.

Game Features
Hybrid Gameplay: Supports both text input and multiple-choice questions.
State Management: Live score calculations and player life points (lives) system.
